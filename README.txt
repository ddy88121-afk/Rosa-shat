روزا — نسخة أولية تجريبية
===========================

الملفات:
- index.html: الصفحة الرئيسية
- style.css: التصميم الأسود والذهبي
- app.js: التفاعلات وحفظ الرسائل محليًا

التشغيل على هاتف Android:
1. فك ضغط rosa_chat.zip في مجلد يسهل الوصول إليه.
2. افتح Acode ثم افتح المجلد rosa_chat.
3. افتح index.html.
4. استخدم Preview / المعاينة لعرض الصفحة.

حدود النسخة الحالية:
- هذه واجهة تجريبية فقط.
- الرسائل تحفظ في localStorage على الجهاز والمتصفح الحاليين فقط.
- لا يوجد حساب مستخدم آمن، ولا خادم، ولا قاعدة بيانات مشتركة، ولا رسائل فورية بين أشخاص على أجهزة مختلفة.
- كلمة المرور هنا لا يتم التحقق منها أو تخزينها؛ لا تدخل كلمة مرور حقيقية.
- غرفة الإدارة ليست محمية أمنيًا. لا تنشر هذه النسخة على أنها دردشة آمنة.

لتحويلها إلى موقع حقيقي متعدد المستخدمين، نحتاج لاحقًا إلى خادم وقاعدة بيانات ومصادقة آمنة، ثم نشرها على استضافة.
دليل معاينة Acode: https://docs.acode.app/user-guide/settings/preview-settings
